# Logic Circuit Builder

A web-based interactive logic circuit builder built with **React** and **Tailwind CSS**.  

You can create logic gates, inputs, and outputs, connect them visually, and simulate circuit behavior.

---

## Features

- Add logic gates: AND, OR, NOT, NAND, NOR, XOR  
- Add inputs and outputs  
- Drag and drop gates, inputs, and outputs  
- Connect gates and inputs to outputs with visual wires  
- Toggle inputs to simulate circuit behavior  
- Clear all components with a single button  

---

## How to Use

1. Open `index.html` in a web browser.  
2. Use the **Gates** buttons to add logic gates.  
3. Use **Components** to add inputs and outputs.  
4. Drag gates, inputs, and outputs to position them.  
5. Click output dots to start wiring → click input or gate dots to connect.  
6. Toggle input buttons to simulate signal changes.  

---

## Tech Stack

- **React** via CDN  
- **Tailwind CSS** via CDN  
- **Lucide React** icons via CDN  
- Vanilla HTML/JS (no build tools required)
